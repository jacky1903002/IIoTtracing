GitHub Pages 專案託管指引

請依照以下步驟部署此專案至 GitHub Pages：

  1. 在 GitHub 建立 Repository，例如：iiot-tracking-system。
  2. 將本單一 HTML 檔案檔名設為 index.html 並 Commit 上傳。
  3. 進入 GitHub Repository 的 Settings 頁面。
  4. 點選左欄 Pages 設定頁。
  5. 在 Build and deployment 的 Source 選擇 Deploy from a branch。
  6. Branch 選取 main / Folder 選取 /(root) 並 Save。
  7. 約 1~2 分鐘後即可使用公開網址登入操作。
